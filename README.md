# PACE project page (Decart Research)

Decart Research version of the project page of *Different Noise Levels, Different Needs: Discovering Diffusion Phases for Efficient Distillation*, published at https://gabrieleserussi.github.io/pace-decart/.

The code, the Colab notebook and the classic version of the page are in [GabrieleSerussi/pace-diffusion](https://github.com/GabrieleSerussi/pace-diffusion). This repository only hosts the page; it is generated from the page source with `configure.py --decart-deploy` and served by GitHub Pages from `main`, root folder.

The brand fonts and textures under `assets/` are Decart's and are not covered by an open license.
